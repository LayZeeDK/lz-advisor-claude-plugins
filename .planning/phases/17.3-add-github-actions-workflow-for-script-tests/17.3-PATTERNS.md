## Pattern Assignments

### `.github/workflows/ci.yml` (config, event-driven)

**Analog:** none in repo. Source pattern is `17.3-RESEARCH.md` "Pattern 1: Single-job,
no-install, glob-discovery test workflow" (lines 166-203), synthesized from the Node 24 test
runner docs and the `actions/setup-node` README. Adapt that verbatim shape; do not search the
codebase for a workflow to mimic (none exists).

**Structure to copy** (from RESEARCH Pattern 1, with the D-decisions applied):
```yaml
name: CI                                    # D-10

on:
  push:
    branches: [main]                        # D-07: post-merge signal only
  pull_request:
    branches: [main]                        # D-07: PR validation; no double-run

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}   # D-08
  cancel-in-progress: true                  # D-08

permissions:
  contents: read                            # D-09: top-level least-privilege

jobs:
  test:                                     # D-10: job id `test`
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@<full-sha>   # v6.0.x; SHA-pin + comment
      - uses: actions/setup-node@<full-sha> # v6.x; SHA-pin + comment
        with:
          node-version-file: .node-version  # D-06: reads lts/<codename>
      - run: >
          node --test --experimental-test-coverage
          --test-coverage-lines=<N>
          --test-coverage-branches=<N>
          --test-coverage-functions=<N>
          "plugins/lz-advisor/skills/**/*.test.mjs"   # D-05: double-quoted glob
```

**SHA-pinning** (RESEARCH Package Legitimacy Audit, lines 99-112; Pitfall 4, lines 247-251):
re-resolve at write time -- `git ls-remote --tags https://github.com/actions/checkout.git` and
`...setup-node.git` -- pick the latest patch of the chosen major (v6), and verify the SHA
appears in the upstream tag output (malicious-fork defense). Starting points captured
2026-06-16:
- `actions/checkout` v6.0.3 -> `df4cb1c069e1874edd31b4311f1884172cec0e10`
- `actions/setup-node` v6.4.0 -> `48b55a011bda9f5d6aeb4c2d9c7362e8dae4041e`
Keep a trailing `# v6.x` comment on each pin so reviewers can cross-check.

**No `npm ci` / `npm install` step** (RESEARCH Anti-Patterns, line 209): there is no
`package.json`; an install step would fail. The `run:` step invokes `node --test` directly.

**Threshold numbers `<N>`** are set after the D-03 measurement run (see Shared Patterns ->
Coverage gate). Prefer 100% on line/branch/function once the bootstrap is excluded.

### `.node-version` (config, static)

**Analog:** none in repo. Format is roadmap-LOCKED by D-06: a single line `lts/<codename>`.

**Content to write** (RESEARCH R-1, line 43; Standard Stack, lines 74-80):
```
lts/krypton
```
- `krypton` = Node 24, Active LTS since 2025-10-28 (VERIFIED against
  `nodejs.org/dist/index.json` `"lts":"Krypton"` and the release schedule).
- Consumed by `actions/setup-node` via `node-version-file: .node-version` (accepts the
  `lts/<codename>` alias) AND by fnm on the dev host -> local/CI resolve the same line.
- Single pinned version, NOT a matrix (D-06).
- Codename-resolution risk (RESEARCH Pitfall 2, lines 235-238): an OLD setup-node manifest can
  fail to resolve a newly-promoted codename (the `lts/jod` #1154 precedent). Mitigate by
  pinning a CURRENT setup-node major (v6) and verifying resolution on the first CI run.
  Fallback ladder if it ever fails: latest setup-node patch -> `lts/*` -> explicit
  `node-version: '24'`, keeping the file as `lts/krypton` (D-06 locks the FILE format).

### Coverage gate (fail-closed, D-02)
**Source:** RESEARCH Code Examples (lines 274-284) + Don't Hand-Roll (lines 217-225).
**Apply to:** the `run:` step in `ci.yml`.
```bash
node --test --experimental-test-coverage \
  --test-coverage-lines=<N> \
  --test-coverage-branches=<N> \
  --test-coverage-functions=<N> \
  "plugins/lz-advisor/skills/**/*.test.mjs"
```
- Thresholds are integers 0-100; below threshold -> process exit code 1 (the gate the job
  inherits). Introduced Node 22.8.0; present in Node 24. Gate on the PROCESS EXIT CODE only --
  do NOT build a reporter keyed off `test:fail` (RESEARCH Pitfall 1: threshold breach exits
  non-zero but historically did not emit `test:fail`).
- Glob MUST be double-quoted so the shell does not expand it -- Node's runner does glob(7)
  expansion itself; this also auto-discovers future `skills/**/*.test.mjs` (D-05).
- `<N>` set after the D-03 measurement run.
