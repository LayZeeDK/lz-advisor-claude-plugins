## Test Infrastructure

|----------|-------|
| **Framework** | `node:test` (built-in) + `node:assert` — zero external deps |

| **Quick run command** | `node --test "plugins/lz-advisor/skills/**/*.test.mjs"` |
| **Full suite command** | `node --test --experimental-test-coverage --test-coverage-lines=<N> --test-coverage-branches=<N> --test-coverage-functions=<N> "plugins/lz-advisor/skills/**/*.test.mjs"` |
| **Estimated runtime** | ~5 seconds (42 tests, stdlib-only) |

## Sampling Rate

- **After every task commit:** Run the quick run command (tests green).
- **After every plan wave:** Run the full suite command (tests + coverage gate green).
- **Before `/gsd:verify-work`:** Full suite + coverage gate must pass; the CI workflow must run green on the pushed branch.
- **Max feedback latency:** ~10 seconds local; one CI run on push/PR.
