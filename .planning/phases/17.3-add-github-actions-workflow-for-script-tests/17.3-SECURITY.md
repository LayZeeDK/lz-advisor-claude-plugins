## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| third-party action -> CI runner | `actions/checkout` / `actions/setup-node` execute in the workflow with the job token; a compromised/forked action runs in our context | action code + GITHUB_TOKEN |
| PR author -> CI workflow | a `pull_request` from a fork triggers ci.yml / test-act.yml and the CI surface it executes | untrusted PR-controlled files |
| GITHUB_TOKEN -> repo | the default token's scope is the blast radius if the runner or an action is compromised | repo read access |
| GitHub -> runner (act) | the runner downloads the act binary + a container image from external registries | untrusted bytes (binary, image) |
| act -> github.com | act clones the SHA-pinned first-party actions over the network using the workflow token | action code |
