# Phase 17.3 Plan 01: GitHub Actions CI for script tests Summary

Stood up a single zero-dependency GitHub Actions CI workflow (`name: CI`, job `test`) that runs the
aggregator's `node:test` suite under Node's built-in coverage on every push/PR to `main`, with a
fail-closed line/branch/function coverage gate enforced via the process exit code -- pinning both
first-party actions to verified peeled upstream commit SHAs and using the locked `lts/krypton` Node
runtime pin.

## What Was Built

- **`.node-version`** (root, new) -- single ASCII line `lts/krypton` (Node 24, Active LTS since
  2025-10-28). Consumed identically by `actions/setup-node` (`node-version-file`) and by fnm (D-06).
- **`.github/workflows/ci.yml`** (new) -- the CI workflow: `name: CI` (D-10); `push.branches: [main]`
  + `pull_request.branches: [main]` (D-07, no double-run); top-level
  `concurrency: group ${{ github.workflow }}-${{ github.ref }}, cancel-in-progress: true` (D-08);
  top-level `permissions: contents: read` only, no job-level escalation (D-09); job id `test` on
  `ubuntu-latest` (D-10). Steps: checkout (peeled SHA pin), setup-node (SHA pin +
  `node-version-file: .node-version`), then a single `node --test --experimental-test-coverage`
  run with the three threshold flags and the double-quoted glob `"plugins/lz-advisor/skills/**/*.test.mjs"`
  (D-05). No `npm ci`/`npm install` (no package.json), no `|| true`.
- **`lz-deep-research-aggregate.mjs`** -- a comment-only `/* node:coverage disable */` /
  `/* node:coverage enable */` pragma bracketing the unreachable CLI bootstrap guard (lines 721-741),
  authorized by D-03; +2 comment lines only, executable code byte-for-byte unchanged.
