This phase ships NO application code, NO auth/authz, NO input handling, NO cryptography, and NO new
attack surface. It edits version strings + markdown and performs outward-facing git/GitHub operations
on a public repo. The only meaningful boundary is the **local working tree / git -> the public
`origin` remote + GitHub Release** (the irreversible publication step). Threats are framed around
**release integrity** (right commit, right tag, right Latest), not web/app exploitation.

| Boundary | Description |
|----------|-------------|
| local git -> origin (public remote) | The merge commit, the `v2.0.0` tag, and the GitHub Release become permanent public artifacts; a wrong-target tag or a leaked secret is hard to retract. |
| authored markdown -> published CHANGELOG / README / Release notes | Content here is world-readable; any secret/token/internal absolute path in it would be published. |
