<objective>
Build the three deterministic gold-anchoring modules of the parity eval: the
judge-MCC-calibration gate (PAR-02; D-13), the AVeriTeC Slice-A filter +
collapse + per-direction descriptive tally + the frozen feasibility gate (PAR-06;
D-11/D-14), and the baseline-capture MANIFEST writer/validator (PAR-03; D-15/D-16).

that produce their inputs are the human-authorized spend in Plan 22-05.

Purpose: these are the construct-validity backstops -- the closed-book gold
(WiCE/LLM-AggreFact) calibrates the JUDGE (it never grades an open-book report);
AVeriTeC's open-book gold scores the open-book verify-voter DESCRIPTIVELY,
per-direction, never pooled (the ratified open-vs-closed-book role separation that
resolves the Phase 18-21 construct VOID). The MANIFEST pins each captured run's
CC-version+model so runs are never averaged across versions (D-16).
Output: three new `eval/*.mjs` modules + co-located FILE-form tests + one small
committed AVeriTeC-shaped fixture, all green.
</objective>
