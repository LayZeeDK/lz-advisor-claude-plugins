<objective>
Build the NO-SPEND deterministic retrieval-log builder (`openbook-retrieval-log.mjs`): it reads the session-dispatched live-web retrieval bundles for the frozen 30 controls from a `.lz-research`-shaped run dir (the same `candidates/`/`claims/`/`excerpts/`/`sources/` layout the extract worker writes, so `joinClusterEvidence` consumes it unchanged), applies the D-07 meta-source blocklist post-filter, pins the fetched_at timestamps, and freezes the snapshot to `eval/.cache/p21-live/openbook-evidence.json` as a uid-keyed, sorted-key object. Purpose: This is the deterministic, no-network, no-spend half of the open-book gold's evidence pipeline (OBG-01 builder + OBG-03 bounded leakage). The actual session-driven Claude retrieval (the live-web search/fetch over the 30 controls) is executed in Plan 04; this plan builds and test-locks the script that consumes that retrieval and enforces the blocklist BEFORE the snapshot is frozen. The enforcement is the gate (a deterministic node post-filter on logged canonical URLs); the search-worker prompt avoidance is best-effort belt-and-suspenders, added in Plan 04. This plan depends on Plan 01 (wave 1) because it imports `filterMetaSources`/`isMetaSource` from `openbook-lib.mjs` -- so it runs in wave 2.

Output: One gitignored script under `eval/.cache/p21-live/` plus its FILE-form test. NO model spend. NO network at import. Tested over a synthetic tmp-fixture run dir.
