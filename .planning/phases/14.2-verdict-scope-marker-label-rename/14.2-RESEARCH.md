## Common Pitfalls

### Pitfall 1: Blanket "scope" -> "axis" replacement shatters the token
**What goes wrong:** A global replace flips `scope: api-correctness` -> `axis: api-correctness`, breaking the downstream parser.
**Why it happens:** "scope" appears in both the label (`**Verdict scope:**`) and the token (`scope: <value>`).
**How to avoid:** Edit each of the 11 sites individually; only the bold label, the 2 `### Verdict scope marker` headers, and the lz-execute:290 prose change. Run gate 6 (token count = 16 unchanged) to catch any accidental token edit.
**Warning signs:** gate 6 returns a count != 16; any `axis: <enum>` appears; `git grep -F 'scope:' -- plugins/lz-advisor/` count drops.

### Pitfall 2: Missing one of the 9 bold-label sites (few-shot drift)
**What goes wrong:** A subset of label sites flips, skills render mixed `Verdict scope:` / `Verdict axis:` output.
**Why it happens:** The label appears 5x in lz-execute alone; easy to miss one.
**How to avoid:** WR-05 atomic commit + gate 1 (`**Verdict scope:**` exits 1) + gate 4 (`**Verdict axis:**` count = 9).
**Warning signs:** gate 1 returns any hit; gate 4 count < 9.

### Pitfall 3: Forgetting the regex metachar in the gate
**What goes wrong:** `git grep '**Verdict scope:**'` (without `-F`) errors or mis-matches on the `**`.
**How to avoid:** Always `-F` for the bold-label patterns (arm64 / Phase 9/14 escaping precedent).
