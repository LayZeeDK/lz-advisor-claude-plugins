- **D-01:** Keep the **fail-hard (abort run)** posture for a malformed `excerpt_id` containing path
  traversal sequences. `safeId()` already throws `ContractError('unsafe id (path traversal

  documenting the chosen posture: "Fail-hard on a malformed `excerpt_id`: a bad path-traversal
  attempt in worker-authored data aborts the entire run rather than silently skipping a member.
  Consistent with the ContractError discipline for all other required fields." No behavior change
  required -- only documentation of the existing posture.

  "can slip to Phase 18 review if bandwidth is tight."

### TEST-2 cross-file-order stability approach

- **D-03:** Use an **inline `tmpRunDir` approach** (no new committed `__fixtures__` dir) for the
  TEST-2 cross-file-order stability test. Create two claim files with names where alphabetical

  file -- regardless of `readdirSync`'s return order. This removes `listJson`'s `.sort()` from
  the "untested" list without adding fixture-dir overhead.
