# Phase 17.1 Plan 01: Aggregator code fixes Summary

Hardened the deterministic deep-research aggregator against six Phase 16/17 review findings on the SOURCE surface: the load-bearing `claims[].id` fail-closed guard (AGG-1), a dead-branch removal in `safeId` (AGG-3), consistent `ContractError.file` annotation on all read/dir failure sites (AGG-5/6/7), and a documented fail-hard posture for a malformed `excerpt_id` (AGG-Q1 / D-01) -- with the existing 19-test `node:test` suite staying green throughout (no behavior regression).

## What Was Built

**Task 1 (`edf07c7`) -- AGG-1 + AGG-Q1:**
- Added a fail-closed guard for a missing/empty `claims[].id` in `mergeClusters`, placed FIRST among the field guards (before `text`/`quote`): `throw new ContractError('claim missing non-empty id', path.join(claimsDir, f))`. This is the one Important source finding -- a missing `id` otherwise coerces to the literal string `"undefined"` in `tally()`'s member-id vote-file fallback (`votes/undefined-0.json`), cross-contaminating vote tallies across all id-less claims. The member-id fallback is in active use (the `wrong-passage-downgraded` / `fabricated-quote-dropped` fixtures name vote files by member id).
- Added an explicit comment in `quoteOutcome` at the `safeId(String(member.excerpt_id))` site documenting the chosen fail-hard posture (AGG-Q1 / D-01): a path-traversal `excerpt_id` aborts the entire run via ContractError, consistent with the ContractError discipline. Comment only -- control flow unchanged.

**Task 2 (`1ba6b56`) -- AGG-3 + AGG-5/6/7:**
- AGG-3: removed the redundant exact-parent-dir equality term from `safeId`'s path-traversal condition (subsumed by `id.includes('..')`); kept the single-dot rejection (`id === '.'`, NOT caught by `includes('..')`). Condition is now `/[\\/]/.test(id) || id === '.' || id.includes('..')`.
- AGG-6: gave `safeId` an optional second `file` param, passed to BOTH its ContractError constructions; `loadExcerpts` now passes the excerpt path so a malformed filename carries `.file`. All other call sites (tally clusterId/memberId, quoteOutcome excerpt_id) are unaffected (param is optional).
- AGG-5: wrapped the bare excerpt `readText` in `loadExcerpts` in a try/catch rethrowing `ContractError('cannot read file: ...', path)`, mirroring `readJson`.
- AGG-7: wrapped the bare `readdirSync` in BOTH `loadExcerpts` and `listJson` in a try/catch rethrowing `ContractError('cannot read dir: ...', dir)`.
