## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Cross-construct gold | Calibrating or grading with closed-book gold for an open-book live-web system. Killed Phases 19/20 directly and Phase 22 indirectly -- relocating the gold to the grader's CALIBRATOR did not escape it. Short-claim-to-long-form transfer collapses AUROC 0.90 -> 0.53 (chance), rankings inverting at Kendall tau -0.64. | blocking | ENV-03/04/06 use no cross-construct gold. Any proposal that reintroduces one must first show the transfer holds ON THE TARGET TASK, not on a proxy. |
| Point-estimate statistical gate at small n | A bar compared against a point estimate whose sampling interval is wider than the distance to the bar. At n=60 the MCC 95% interval is [0.284, 0.728] and P(false fail) is ~47% for a judge AT the bar -- and raising n does NOT reduce that rate, because the median stays on the bar. | blocking | Gate on a lower-bound CI, or set the point bar meaningfully below the target. Never read two near-bar misses as evidence about the instrument. |
| Agent-side scope reduction carried forward as settled design | Phase 22's n=3 -> n=1 Slice-B reduction: the maintainer DEFERRED the full campaign, and the executing session then carried n=1 forward as though ratified. No amendment covers it. | blocking | ENV-01 + termination branch (c): any descope is amended into the pre-registration AT THE TIME IT IS TAKEN, with maintainer ratification recorded. A deferral is not a ratification. |
| GSD SDK mutator side effects on STATE.md / config.json | Observed again this session: `query phase.add` DELETED `branching_strategy` from `.planning/config.json`; `query state.add-roadmap-evolution` REGRESSED `last_activity_desc` to a stale Phase-22 Plan-04 line contradicting `stopped_at`. | Format-sensitive citation metrics | The two systems cite differently -- the built-in uses numbered references to arXiv identifiers in prose (0 inline URLs in the q1 report); lz uses full inline URLs. A naive URL-counting metric would silently favour lz. | advisory | ENV-04 freezes citation-format normalization BEFORE any rate is computed. |
