string replacement value. This is the escalated Phase-22 defect T-22-15: with a string replacement,

are interpreted as special patterns instead of inserted literally, which silently mangles the
instrument. Measured in Phase 22: 27 of 60 records carried a dollar sign and none carried a hazardous
sequence, so that run was not corrupted -- the fix is one call site per substitution and it lands
before verdict one. Prefer building the string by array join over a template scan if that removes the
substitution surface entirely; take whichever route the co-test can prove verbatim round-tripping for.

justification, the fact-checking article, the questions, the speaker, or the `drawIndex`.

Export `writeDispatchRecord({ dir, drawIndex, direction, sent })`. It writes the exact dispatched
string and its `node:crypto` sha256 hex digest to a per-item file keyed by direction and `drawIndex`,
and throws a `ContractError` rather than overwriting an existing record -- the write-once discipline
that makes a partial re-roll distinguishable from a resume. This is what closes SEED-005: after the
run, "what the instrument actually was" is recoverable from disk instead of being an unverifiable
assumption.

Export `readSliceAVerdicts({ dispatchDir, verdictDir })`.
