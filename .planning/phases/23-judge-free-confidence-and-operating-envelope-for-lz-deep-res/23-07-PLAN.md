<objective>
Run the deterministic citation audit over the fresh q2 pair and publish it as the ENV-04 reading of
record.

This is where the D-02 route pays off: the bar is set on a pair no session had seen before the capture,
on rules frozen two waves earlier, using the same module a published dry run already exercised on real
data. Nothing about the metric is being decided here -- it is being applied.

Purpose: ENV-04 is the phase's comparative reading that needs no judge and no gold. It reports what can
be checked mechanically -- identifier resolvability, unique canonical sources, verbatim-quote match
against retained excerpts, and structural citation coverage -- and it says plainly what it does not
measure.
Output: one committed durable record opening with a single machine-readable `ENV-04 status:` line, plus
whichever per-system audit outputs and dated resolvability envelope the branch produced.

**The branch is read, never assumed.** Plan 23-06 Task 1 is a blocking-human checkpoint with three
sanctioned outcomes, and two of them do not produce a full pair: option B captures the lz side only,
option C descopes both q2 captures under termination branch (c), which the ROADMAP pre-registered as a
valid completion. So this plan audits whichever admissible q2 reports EXIST -- two, one or none -- and
never requires two to exist. Every check here is conditional on what is on disk, and the status line is
what makes which branch was taken legible to Plan 23-09 and to the milestone audit. Under NOT-RUN this
plan still completes and still publishes: the q1 dry run stands alone as a published dry run and the
ENV-04 bar becomes a named not-established item with the recorded amendment as its result-independent
reason. That is the same shape Plan 23-08 uses for its own conditional, and it is deliberate that the
two match.

Zero model spend. The only network access is the resolvability half, which is dated, isolated, and
something the offline reading does not depend on.
</objective>
