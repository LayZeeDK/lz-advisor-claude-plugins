<objective>
Run the deterministic citation audit over the fresh q2 pair and publish it as the ENV-04 reading of
record.

This is where the D-02 route pays off: the bar is set on a pair no session had seen before the capture,
on rules frozen two waves earlier, using the same module a published dry run already exercised on real
data. Nothing about the metric is being decided here -- it is being applied.

Purpose: ENV-04 is the phase's comparative reading that needs no judge and no gold. It reports what can
be checked mechanically -- identifier resolvability, unique canonical sources, verbatim-quote match
against retained excerpts, and structural citation coverage -- and it says plainly what it does not
measure.
Output: two per-system audit outputs, one dated resolvability envelope, and one committed durable
record carrying the q2 rows as the reading of record with the q1 rows beside them, separately labelled
and never averaged.

Zero model spend. The only network access is the resolvability half, which is dated, isolated, and
something the offline reading does not depend on.
</objective>
