## The 10 converged decisions (UNANIMOUS, facts only)

- DP1 BATCH SIZE: default 8 packets/call, hard cap 10; hard near-boundary trap packets (incl. the unresolved "more than doubled" divergence item) ride in <=6-packet batches (false-accept is the catastrophic direction; batch length is the only knob that trades against it). Proven clean parse at batch 6; ~21k/call overhead makes call-count the cost driver; list-length failure modes grow with length.
- DP2 OUTPUT + PARSER: JSON array `[{"id","entails","reason"}]`, parsed by the EXISTING eval/.cache/oof-probe/score.mjs fence-strip + first-`[`/last-`]` slice (already proven on cheap + frontier models; tolerates conversational filler). Not XML.
- DP3 PARSE-FAILURE = FAIL-CLOSED TO DROP: missing/extra/duplicate id, non-boolean entails, truncation, or a batch-level summary -> that packet UNRESOLVED = probe-decline = counted in attrition.probeDropped; a whole-batch JSON failure re-runs the batch once, then splits it in half. Dropping shrinks N but cannot fabricate gold; runProbeConsensus already short-circuits a declined judge; below-floor is a documented VOID.
- DP4 CONTAMINATION GATE (run once before trusting bulk): >=11/12 exact single-vs-batched entails agreement PER MODEL on a 12-packet hardest slice, INCLUDING one reversed-order variant; no separate distractor check (order robustness is otherwise covered by the pilot's k=5 reshuffles). 11/12=91.7% tolerates one benign near-determinism flip; 100% would false-trip.
- DP5 CHEAP PRE-FILTER: none in the committed gold-build path (negligible savings after batching); IF batch-routing/sizing is ever added it MUST be strictly membership-neutral (never removes a packet from frozen-pair judgment) and is non-gating by construction. A membership-changing filter = a frozen-decider-identity amendment.
- DP6 CHEAPER MODELS = NON-GATING ONLY: the frozen pair (gpt-5.5 + gemini-3.1-pro-preview, --effort high) is the SOLE gating retain decider. Cheapest pair after batching saves only ~$2; decider identity + all-agree rule are frozen.
- DP7 CHEAPER-MODEL PILOT (separate, non-gating): n=66 = 36 traps / 30 controls; >=18 of the 36 traps are hard near-boundary incl. the "more than doubled" divergence item; k=5 by reshuffling packet order across 5 batched runs. 36 = N_TRAP_FLOOR (CP1s(0,36)=0.0798<=TAU_FU 0.10; CP1s(1,36)=0.1251 fails -> trap arm 0-miss-only); 30 controls tolerate one over-refusal (CP1s(1,30)=0.1486<=TAU_OR 0.15) where 24 would not (CP1s(1,24)=0.1829); +6 controls ~= +1 batched call. (Engine-verified anchors via the frozen clopperPearsonUpperOneSided; cp-anchors.mjs.)
- DP8 PILOT STATISTIC: one-sided Clopper-Pearson UPPER on the per-ARM PACKET counts (false-accepts/36 traps; false-vetoes/30 controls) via the frozen clopperPearsonUpperOneSided; k=5 self-consistency reported separately. NOT pooled over n*k (Pitfall 3: k votes on one packet are positively correlated -> anti-conservative).
- DP9 PRE-REGISTERED PROMOTION THRESHOLDS (cheap model -> role), fixed before the pilot runs: diagnostic-annotator (always allowed, no gold impact) = self-consistency >=95% AND frozen-pair agreement >=60/66 (~90%); pre-filter (only if ever membership-neutral, per DP5) = agreement >=62/66 AND zero false-accepts on the 36 traps; decider (AMENDMENT-ONLY) = 0 false-accepts on the 36 traps (CP1s(0,36)=0.0798<=0.10; one fails, would need N>=46) AND control-arm CP1s(falseVetoes,30)<=0.15 (0 or 1 over-refusal clears) AND <=1 k=5 self-split AND agreement >=62/66.
- DP10 k=1 MAIN GATE VIA STABILITY CERTIFICATE: if the frozen pair is recorded 100% self-consistent across the pilot's k=5 reshuffles, run the MAIN gold-screen at k=1 (one batched pass) with the certificate recorded. --effort high is near-deterministic; the prior reviewers' "need k>=5" concerned ESTIMATING a rate, which a one-time stability measurement addresses; this concerns gating stability ONLY -- NOT the downstream per-voter k=9 false-uphold rate (that arm keeps its votes).
